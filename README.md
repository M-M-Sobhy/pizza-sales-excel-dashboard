# Pizza Sales Excel Dashboard 🍕📊

An interactive, dynamic Excel dashboard designed to analyze and visualize pizza sales performance data. This project transforms raw transactional data into actionable business insights using advanced Excel features like Pivot Tables, Pivot Charts, and interactive Slicers.

## 🚀 Features

* **Key Metrics at a Glance:** Instantly view high-level KPIs like **Total Sales ($8,436)**.
* **Time-Series Analysis:** * **Order Trend by Hours:** Identifies peak operational hours (e.g., peak demand at 5:00 PM).
  * **Total Orders by Week Day & Day:** Tracks weekly patterns to optimize staffing and inventory.
  * **Total Orders per Quarter:** Monitors seasonal sales distributions.
* **Product Performance:** Breaks down quantity distributions by **Pizza Size** (S, M, L, XL).
* **Interactive Slicers:** Dynamic sidebar filters allowing users to slice data instantly by **Order Date**, **Pizza Category** (Chicken, Classic, Supreme, Veggie), and **Pizza Size**.

---

## 🛠️ Tools & Techniques Used

* **Microsoft Excel:** Core platform used for data processing and visualization.
* **Pivot Tables & Pivot Charts:** Utilized to aggregate large datasets and build dynamic visual components.
* **Data Modeling:** Formatted and structured relational data for seamless dashboard integration.
* **UI/UX Dashboard Design:** Applied a cohesive color palette, clear typography, and a scannable grid layout for an intuitive user experience.
